# Awesome-Low-Code-Application-Development-Lcap

# Top Low-Code Application Development (LCAP) Tools Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Visual App Building, Citizen Development & Enterprise Application Delivery*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Low-Code Application Development Platforms (LCAP)**. These tools enable organizations to build web and mobile business applications through visual builders, drag-and-drop interfaces, and declarative configuration — reducing hand-coding while maintaining enterprise governance, integration, and scalability.

**Examples** include Salesforce Lightning Platform, Microsoft Power Apps, OutSystems, Mendix, Appian, Quickbase, Zoho Creator, Caspio, Retool, and ServiceNow App Engine (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom application delivery, and transparent development workflows — ideal for organizations seeking data sovereignty, developers building internal tools, and teams avoiding vendor lock-in.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Microsoft Power Apps](https://powerapps.microsoft.com/)**

- **[OutSystems](https://www.outsystems.com/)**  
  High-performance low-code platform for enterprise web and mobile applications. Named a Leader in Nucleus Research's 2025 LCAP Technology Value Matrix  and a Market Leader in FeaturedCustomers Summer 2026 .

- **[Mendix](https://www.mendix.com/)**  
  Low-code application development platform with visual modeling, multi-cloud deployment, and enterprise integration. Ranked as an Expert vendor in Nucleus Research 2025 LCAP Value Matrix .

- **[Appian](https://appian.com/)**  
  Enterprise low-code automation platform with process modeling, case management, and RPA orchestration. Named a Market Leader in both Nucleus Research 2025 and FeaturedCustomers Summer 2026 .

- **[Quickbase](https://www.quickbase.com/)**  
  No-code platform for building custom business applications with relational databases and workflow automation. Named a Market Leader in FeaturedCustomers Summer 2026 .

- **[Zoho Creator](https://www.zoho.com/creator/)**  
  Low-code platform for building custom applications with drag-and-drop interface, scripting, and integration with Zoho ecosystem. Named a Leader in Nucleus Research 2025 LCAP Value Matrix .

- **[Caspio](https://www.caspio.com/)**  
  No-code platform for building database-driven applications with forms, reports, and workflows on managed cloud database.

- **[Retool](https://retool.com/)**  
  Low-code platform for building internal tools with drag-and-drop components, database and API connectors. Named a Core Provider in Nucleus Research 2025 LCAP Value Matrix .

- **[ServiceNow App Engine](https://www.servicenow.com/)**  
  Enterprise low-code platform within ServiceNow for building custom applications, workflows, and process automation. Named an Expert vendor in Nucleus Research 2025 LCAP Value Matrix .

## Open-Source GitHub Projects

- **[Lowcoder](https://github.com/Nangelov7/lowcoder)**  
  Open-source all-in-one IDE for building internal and customer-facing applications (continuation of abandoned Openblocks project). Features 120+ components, free layout design, native embedding in websites without iFrames, video meeting components, query library, and self-hosting. Positioned as alternative to Retool, Tooljet, and Appsmith. 5,800+ GitHub stars .

- **[Budibase](https://github.com/Budibase/budibase)**  
  Open-source low-code platform for building business apps and workflows in minutes. Supports PostgreSQL, MySQL, MariaDB, MSSQL, MongoDB, REST API, Docker, and Kubernetes. 22,700+ GitHub stars .

- **[Windmill](https://github.com/windmill-labs/windmill)**  
  Open-source developer platform to turn scripts into webhooks, workflows, and UIs. Fastest workflow engine (13x vs Airflow). Open-source alternative to Retool and Temporal. GPL-1.0+ licensed, 18,000+ GitHub stars .

- **[Sovrium](https://socket.dev/npm/package/sovrium)**  
  Configuration-driven web application platform built with Bun, Effect, React, and Tailwind CSS. Open-source alternative to Airtable, Retool, and Notion. Self-hosted, no vendor lock-in. Write a config file, run one command, and your app is live with tables, API, authentication, pages, theming, and i18n .

- **[pgkiln](https://www.npmjs.com/package/pgkiln)**  
  Low-code, SQL-driven application builder for PostgreSQL, modeled on Oracle APEX. Applications are data: pages, regions, items, and processes are rows in a meta schema. Includes MCP server for AI coding agents, responsive PWA support, and row-level security .

- **[NocoDB](https://github.com/nocodb/nocodb)**  
  Open-source Airtable alternative that turns any SQL database into a smart spreadsheet with grid, gallery, kanban, calendar, and form views. 62.7k+ GitHub stars. Auto-generated REST APIs, webhooks, and role-based access control .

- **[Baserow](https://github.com/baserow/baserow)**  
  Open-source no-code platform for building internal tools, databases, and business applications. Self-hosting, API-first architecture, real-time collaboration, and database management. Airtable alternative for teams needing customization and data ownership .

- **[Convertigo](https://github.com/convertigo/convertigo)**  
  Open-source low-code and no-code platform for web, mobile, and desktop business applications. Dual-licensed AGPLv3/commercial with FullSync offline synchronization, enterprise connectors, MCP server for AI agents, and customer-controlled deployment. Positioned as sovereign alternative to Power Apps, OutSystems, and Mendix .

- **[Joget DX](https://github.com/jogetworkflow/jw-community)**  
  Open-source AI-powered platform converging no-code/low-code development with AI. Visual app builder with Generative AI and Agentic AI capabilities, extensible plugin architecture, and white-label options .

- **[NocoBase](https://github.com/nocobase/nocobase)**  
  Extensible-first, open-source no-code/low-code platform for building business applications and enterprise solutions. 13,000+ GitHub stars .

- **[ToolJet](https://github.com/ToolJet/ToolJet)**  
  Extensible low-code framework for building business applications with visual app builder and 50+ data source connectors .

- **[Appsmith](https://github.com/appsmithorg/appsmith)**  
  Open-source low-code platform for building internal tools with 45+ widgets, DB & API connectivity, and GitHub integration. 34,000+ GitHub stars .

- **[REI3](https://github.com/rei3/rei3)**  
  Free and open low-code application platform. Build multi-user applications rapidly. Open source with online and self-hosted options .

- **[Jmix](https://github.com/jmix-framework/jmix)**  
  Open-source full-stack framework with Rapid Application Development tools for business web applications. Apache 2.0 licensed, aimed at professional developers .

### Additional Strong Open-Source Options

- **[Lowdefy](https://github.com/lowdefy/lowdefy)** — Config web stack for business apps using YAML or JSON. 2,600+ GitHub stars .
- **[Grist](https://github.com/gristlabs/grist-core)** — Modern relational spreadsheet with Python formulas and access controls. 7,200+ GitHub stars .
- **[Teable](https://github.com/teableio/teable)** — Next-gen Airtable alternative built on PostgreSQL .
- **[Illa Builder](https://github.com/illacloud/illa-builder)** — Low-code platform for building business apps with automation workflows. 11,500+ GitHub stars .
- **[DashPress](https://github.com/dashpresshq/dashpress)** — Generate powerful admin apps without writing code. 1,700+ GitHub stars .

**Frameworks for building custom systems**: Combine **Lowcoder** or **Budibase** for visual app building, **Windmill** for developer-first workflows, **pgkiln** for PostgreSQL-native applications, **NocoDB** or **Baserow** for database-driven tools, and **Convertigo** for enterprise-grade mobile and web apps to build a complete self-hosted low-code development stack.
